AIRIS — AI Settings

One AI configuration for every feature

Chat, code patching, screen vision, YouTube summaries, memory utilities and the terminal all use these values. Changes apply app-wide without restarting (renderers listen for updates) and are saved to data/ai-config.json.

Provider & endpoint

Presets only fill the base URL below — you can always edit it. Any OpenAI-compatible /v1 endpoint works.
Examples: http://localhost:1234/v1 (LM Studio), http://127.0.0.1:8080/v1 (llama.cpp), a hosted compatible endpoint. Duplicate /v1 segments are cleaned automatically.
